# FREEMAN — Иврит для жизни

Готовый статический сайт для репозитория `freemanhebrew/ivritwithfreeman`.

## Как заменить старый сайт

1. Сохрани копию старых файлов или создай отдельную ветку перед заменой.
2. Распакуй ZIP на компьютере.
3. Загрузи распакованные файлы и папку `assets` в папку, из которой GitHub Pages уже публикует сайт. Загружать сам ZIP не нужно.
4. Замени старые `index.html`, `style.css`, `app.js` и `favicon.svg`, добавь `reviews.js` и обновлённую папку `assets`. `index.html` должен находиться прямо в папке публикации, без дополнительной вложенной папки.
5. Сохрани изменения в репозитории и дождись завершения публикации GitHub Pages.
6. Открой https://freemanhebrew.github.io/ivritwithfreeman/ и обнови страницу без кеша. Проверь мобильную версию, кнопки Telegram/Tribute, переключение длительности уроков и PDF регламента.

Если публикация настроена на корень репозитория, помещай файлы туда. Если на папку `docs`, помещай файлы в `docs`. Существующую настройку публикации и файлы `.github` менять не нужно.

## Что находится в архиве

- `index.html` — страница сайта.
- `style.css` — оформление и адаптивная версия.
- `app.js` — анимации, фильтры отзывов и переключение тарифов.
- `reviews.js` — полные тексты отзывов.
- `favicon.svg` — значок сайта.
- `assets/` — фотографии, логотип и PDF регламента.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Сборка и установка зависимостей не нужны. Пути к файлам уже адаптированы к адресу GitHub Pages `/ivritwithfreeman/`. Шрифты загружаются из Google Fonts.

Состояние: все согласованные изменения, включая личную систему индивидуального обучения, уровни с ориентирами CEFR, написание «hэй» и «20+ лет жизни в иврите».
